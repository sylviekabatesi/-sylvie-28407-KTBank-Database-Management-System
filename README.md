# KTBank – Peer-to-Peer Currency Transfer System

## 1. Project Overview
KTBank is a multi-currency banking management system developed using Oracle Database 21c and PL/SQL. The project aims to simplify banking operations by supporting deposits, withdrawals, peer-to-peer money transfers, and currency conversion.

## 2. Problem Statement
Traditional banking transactions involving multiple currencies can be challenging to manage, track, and process accurately. This may result in transaction errors, delays, and limited transparency.

## 3. Project Objectives
- Manage customer bank accounts.
- Process deposits and withdrawals.
- Support peer-to-peer money transfers.
- Perform multi-currency conversion.
- Maintain accurate transaction records.
- Improve transaction security and auditing.

## 4. Technologies
- Oracle Database 21c
- PL/SQL
- Oracle SQL Developer

## 5. Planned Features
- Customer and account management.
- Deposit and withdrawal procedures.
- Money transfer functionality.
- Currency exchange management.
- Transaction history and auditing.
- Automated fraud detection (planned enhancement).

## 6. Project Status
Currently under development. Features will be implemented and tested progressively.
